# Contributing

Thanks for your interest in the GTA VI for Windows 11 project.

## Before contributing

- Read the [README](README.md) and [architecture notes](docs/ARCHITECTURE.md).
- Keep changes focused and explain the problem they solve.
- Target Windows 11 only.
- Do not submit Rockstar-owned game assets, leaked files, proprietary source code, or unauthorized game executables.
- Do not add DRM, anti-cheat, account, or platform-protection bypasses.
- Do not claim compatibility or performance without reproducible evidence.

## Pull requests

Include:
- A concise summary of the change.
- The Windows 11 version and architecture tested.
- Build and test steps.
- Screenshots or logs when they clarify a UI or diagnostic change (redact personal information).

Small, reviewable pull requests are preferred. Discuss major architectural changes in an issue before investing in a large implementation.
