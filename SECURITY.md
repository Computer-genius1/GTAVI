# Security Policy

## Scope

This repository is at an early planning stage. Security reports are welcome for code and build infrastructure that is actually present in this repository.

## Reporting a vulnerability

Please use GitHub's **Private vulnerability reporting** feature for this repository if it is enabled. If it is unavailable, open a minimal issue asking for a private contact method; do not publish exploit details, credentials, or personal information in a public issue.

Include the affected file or component, impact, reproduction steps, and any suggested mitigation. Do not attach private keys, passwords, account tokens, or unrelated personal data.

## Supported versions

There are no released application versions yet. Security fixes will be tracked as implementation begins.
